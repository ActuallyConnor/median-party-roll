# Median Party Roll

Median Party Roll is a Foundry VTT module that lets a GM choose active players, request a roll from each of them, and publish the median result to chat.

## Install locally

1. Copy the `median-party-roll` folder into your Foundry `Data/modules` folder.
2. Restart Foundry or return to Setup and refresh modules.
3. Enable **Median Party Roll** in your world.

## Use

1. Log in as GM.
2. Click the d20 tool in the Token controls or the **Median Roll** button near chat controls.
3. Choose players, enter a roll formula, and request rolls.
4. Each selected player gets a roll dialog.
5. When all selected players have rolled, the sorted results and median are posted to chat.

For an even number of players, the module reports the average of the two middle rolls and highlights both middle rollers.
